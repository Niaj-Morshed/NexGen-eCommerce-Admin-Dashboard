📊 NexGen – Advanced eCommerce Admin Dashboard & Analytics
-----------------------------------------------------------
Live Demo: https://niaj-morshed.github.io/NexGen-eCommerce-Admin-Dashboard/


🚀 Overview:
-------------
NexGen is a modern and data-driven admin dashboard designed to track sales, inventory, and  
customer activity for e-commerce businesses. The project focuses on data visualization,
which helps a business owner make informed business decisions.


✨ Key Features:
-----------------
1. 📈 Real-Time Data Visualization
     * Interactive sales charts and revenue graphs
     * Visual representation of order status (Pending, Shipped, Delivered)
     * Comparison cards for weekly/monthly growth

2. 📦 Inventory & Product Management
     * Comprehensive product table with search and filter options
     * Stock status indicators (In Stock, Low Stock, Out of Stock)
     * Add/Edit/Delete product simulation UI

3. 👥 Customer Insights & Activity
     * User management panel with detailed customer lists
     * Recent activity log tracking new orders and registrations
     * Top-selling product list with performance metrics

4. 💰 Financial Overview Cards
     * Quick-view stats for Total Sales, Net Profit, and Expenses
     * Animated counter effects for numeric data
     * Color-coded profit/loss indicators

5. 🌙 Dynamic Theme System
     * Dark and Light mode support for long-hour productivity
     * High-contrast design for better readability
     * Smooth theme transitions using CSS Variables

6. 📱 Responsive Control Panel
     * Sidebar navigation that adapts to mobile and tablet views
     * Collapsible menu for a wider workspace
     * Fully functional on all modern web browsers

7. 🎨 Pro UI/UX Features
     * Glassmorphism sidebar and header design
     * Custom notification bell with badge alerts
     * Clean, minimalist layout focusing on data clarity
     * Hover-reveal effects on data rows



🛠️ Technologies Used:
----------------------
1. Core Stack
     * HTML5: Semantic markup for structured data presentation.
     * CSS3: Advanced Grid and Flexbox for complex dashboard layouts.
     * JavaScript (ES6+): Logic for dynamic data rendering and theme switching.

2. Libraries & Assets
     * Chart.js / ApexCharts: (If used) For rendering interactive and beautiful graphs.
     * Font Awesome: For intuitive admin and management icons.
     * Google Fonts: Using "Inter/Roboto" for a professional look.

3. Development Techniques
     * LocalStorage: To persist user preferences like theme mode.
     * Custom Transitions: For a smooth, high-end application feel.
     * Modular CSS: Keeping the dashboard scalable and easy to maintain.
